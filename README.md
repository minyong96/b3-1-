# 🧹 클라우드 리소스 정리 체크리스트 (Cleanup Checklist)

본 문서는 실습 및 테스트 종료 후 불필요한 과금을 방지하기 위해 생성된 AWS 리소스의 해제 및 삭제 내역을 기록하는 체크리스트입니다.

## 1. 컴퓨팅 (EC2)
- [ ] **EC2 인스턴스 종료 (Terminate)**
  - 인스턴스 ID: (예: `i-0123456789abcdef0`)
  - 인스턴스 상태가 `Terminated` (종료됨) 상태인지 확인


## 2. 네트워크 (VPC 및 게이트웨이)
- [ ] **인터넷 게이트웨이(IGW) 분리 및 삭제**
  - VPC에서 IGW를 `Detach` 한 후 삭제 완료
- [ ] **라우팅 테이블(Route Table) 삭제**
  - 퍼블릭 서브넷에 연결된 커스텀 라우팅 테이블 삭제
- [ ] **서브넷(Subnet) 삭제**
  - 퍼블릭 서브넷(`10.0.1.0/24`) 삭제 완료
- [ ] **VPC 삭제**
  - `10.0.0.0/16` VPC 최종 삭제 완료

## 3. 보안 (Security Group & IAM)
- [ ] **보안 그룹(Security Group) 삭제**
  - 웹서버용으로 생성한 커스텀 보안 그룹 삭제 완료
- [ ] **실습용 IAM 사용자(또는 Role) 정리** (필요시)
  - 실습용으로 발급했던 IAM 사용자 삭제 또는 액세스 키 비활성화
